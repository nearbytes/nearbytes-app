Nearbytes UI specification · shared state machine

Four state layers. Never more than one active surface per layer.

The shared UI becomes correct when state ownership is explicit. This machine separates primary workspace, secondary product surfaces, and interruptive modal flows so the UI can remain simple while preserving all current capabilities.

Rule 1
Overflow opens a secondary sheet. It does not silently toggle a mix of independent flags.
Rule 2
Modal entry points set modalFlow. Escape, dismiss action, or successful completion clears it.
Rule 3
Changing the current hub leaves the shell alive but clears hub-bound transient sheet state that would become misleading.
Rule 4
Phone and desktop share the same machine. Desktop may render a side sheet; phone may render a bottom sheet or takeover. The state is identical.
